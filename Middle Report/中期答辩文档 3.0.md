## 二、代码规范约定

- **是否开展结构化设计**：是
- **命名规范**：模块名称使用驼峰命名法；模块接口及内部信号线使用下划线命名法。
- **注释要求**：
  1. 使用英文注释；
  2. 注释模块的接口与功能；
  3. 注释代码块对应的指令类型
- **符号化常量的定义及使用**：
  - 规定：代码中涉及的常量（数字）应定义为参数（`parameter`）；若直接出现在代码中，应加注释。
  - 常量包含：不同指令对应的 `opcode`/`funct3`/`funct7`；分频的时钟频率；按钮消抖时间的阈值

## 三、CPU特性说明

- **CPU结构**：分别实现单周期 CPU 和 Pipelined CPU
- **单周期时钟周期**：23MHz (CPU);  10MHz (UART)
- **寻址空间设计**：哈佛结构
- **IO方式**：利用 `ecall` 进行输入输出
- **支持的指令集**：RISC-V32
  已实现 blackboard 提供的 RISC-V32 Reference Card 第一页的全部指令（不包含 `ebreak`；`ecall`支持 `2`,`34`,`35`）

  | 类型               | 指令                                           |
  | ------------------ | ---------------------------------------------- |
  | `R-type (0110011)` | `add,sub,xor,or,and,sll,srl,sra,slt,sltu`      |
  | `I-type (0010011)` | `addi,xori,ori,andi,slli,srli,srai,slti,sltiu` |
  | `I-type (0000011)` | `lb,lh,lw,lbu,lhu`                             |
  | `I-type (1100111)` | `jalr`                                         |
  | `I-type (1110011)` | `ecall(2,34,35)`                               |
  | `S-type (0100011)` | `sw,sh,sb`                                     |
  | `B-type (1100011)` | `beq,bne,blt,bge,bltu,bgeu`                    |
  | `U-type (0110111)` | `lui`                                          |
  | `U-type (0010111)` | `auipc // single cycle CPU`                    |
  | `J-type (1101111)` | `jal`                                          |
