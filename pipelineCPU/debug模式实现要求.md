debug模式实现要求：

1，要有一个拨码开关来控制debug模式和正常模式的切换。

2，debug模式中，时序额外受一个控制信号控制（暂定名`en_pc2`），控制效果，初始值同`en_pc`：高电平时时钟正常，低电平时主时序（上升沿时序）停止。`en_pc2`在正常模式恒为1；在debug模式常为0，仅当一个按钮按下时有一个时钟周期的1。（为了安全起见，可以是下降沿-下降沿的一个时钟周期，以使之能在上升沿发挥作用时稳定）

3，因为我们希望把机器码和一些辅助信息传递给前端，所以机器码的线要一直往后接。控制信号包括`en_pc,clr_if,is_stalling`和一些Forward有没有发生的信号都要打包发给前端。即后端要把5个inst和一个控制信号，Forward标示组成的集体共计6个32位的东西发给前端。（也可以在加一个pc，这样就是7个了）

4，前端的显示应该做到以下效果：显示`IF,ID,EXE,MEM,WB`五列，若干行，每行表示某个时钟周期内的所有指令。

效果大致如下

| IF    | ID    | EXE   | MEM   | WB   |
| ----- | ----- | ----- | ----- | ---- |
| inst1 |       |       |       |      |
| inst2 | inst1 |       |       |      |
| inst3 | inst2 | inst1 |       |      |
| inst4 | inst3 | inst2 | inst1 |      |

pc可以单独显示此刻的pc（即不用若干行）

控制信号的显示逻辑需要参考后端实现，需要由wzy和lzt沟通一下。
